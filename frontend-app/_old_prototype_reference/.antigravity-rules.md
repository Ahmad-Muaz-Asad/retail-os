# Antigravity Global Rules & Tech Stack

## Core Technology Stack
- **Frontend Framework:** Next.js (App Router).
- **Styling:** Tailwind CSS.
- **Language:** Strictly TypeScript (Avoid using `any` types).
- **Backend/API:** Next.js Server Actions / API Routes.
- **Database:** Prisma ORM with local SQLite.
- **AI Integration:** Groq API (LLM) + standard fetch requests.

## Development Constraints
- **UI/UX:** Build mobile-responsive, clean, and minimalist interfaces. Use Tailwind for all styling.
- **Database Rules:** Never create or modify database tables without explicit permission in the prompt. All database queries must be executed via the Prisma client.
- **Agent Behavior:** Do not attempt to build the entire system at once. Follow the module-by-module breakdown. Always generate an "Implementation Plan" artifact for user review before writing bulk code.
